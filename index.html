Lab 04 - Windows Event Viewer Log Analysis

Explored the Application, System and Security logs in Windows Event Viewer, identified key security Event IDs such as 4624 (successful logon) and 4625 (failed logon), filtered log entries, and exported events for later analysis.

  • Event Viewer
  • Log Analysis
  • Event IDs
View Lab 04

Lab 05 - Windows Security Hardening

Assessed a Windows 10 endpoint against a security baseline. Found the firewall disabled on all three profiles and a weak password policy, then enabled the firewall with default inbound blocking and enforced a 12-character minimum, complexity and password history. Confirmed Defender and UAC were already configured correctly.

  • Windows Firewall
  • Defender
  • UAC
  • Password Policy
View Lab 05

Lab 06 - Active Directory Domain Controller

Built a Windows Server 2022 domain controller (lab.local), joined a Windows 10 client, and created an OU, a user and a security group. Enforced a Group Policy that blocks Control Panel and troubleshot a Kerberos clock-sync failure along the way.

  • Active Directory
  • Group Policy
  • Windows Server
  • DNS
